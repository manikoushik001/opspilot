# Demo Learning Center - Course Catalog

## 1. Weekend Java Masterclass
- **Duration**: 12 Weeks (Saturdays & Sundays, 10:00 AM - 1:00 PM)
- **Level**: Beginner to Intermediate
- **Curriculum**:
  - Core Java Syntax, Object-Oriented Programming (OOP)
  - Data Structures, Collections Framework, Generics
  - Spring Boot 3, REST API Design, Hibernate & JPA
  - PostgreSQL Database Integration & Testing
  - Microservices basics and Docker deployment
- **Prerequisites**: Basic computer literacy. No prior programming experience required.
- **Certification**: Certificate of Full-Stack Java Competency upon capstone project completion.

## 2. Python for Data Science & AI
- **Duration**: 10 Weeks (Tuesdays & Thursdays, 6:30 PM - 9:00 PM)
- **Level**: Intermediate
- **Curriculum**:
  - Python fundamentals, NumPy, Pandas, Data Cleaning
  - Exploratory Data Analysis, Data Visualization (Matplotlib, Seaborn)
  - Machine Learning with Scikit-Learn
  - Introduction to Large Language Models (LLMs) & RAG Systems
- **Prerequisites**: High-school mathematics and basic logic reasoning.

## 3. Full-Stack Web Development (React & Node.js)
- **Duration**: 14 Weeks (Mondays & Wednesdays, 6:00 PM - 9:00 PM)
- **Level**: Beginner to Advanced
- **Curriculum**:
  - HTML5, CSS3, Tailwind CSS, TypeScript
  - React 19, Next.js App Router, TanStack Query
  - Node.js, Express, PostgreSQL, Prisma ORM
  - Authentication (JWT), WebSockets, CI/CD Deployment

## 4. UI/UX Product Design Intensive
- **Duration**: 6 Weeks (Saturdays, 2:00 PM - 6:00 PM)
- **Level**: Beginner
- **Curriculum**: Figma masterclass, Design systems, Wireframing, Usability testing.
